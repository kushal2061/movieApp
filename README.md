# 🎬 Movie App (React)

A simple movie browsing web application built using React.js.  
This app fetches movie data from an external API and allows users to explore popular movies, search for movies, and manage their favorite list.

---

## 🚀 Features

- 🔥 Display popular movies on home page
- 🔍 Search movies by name
- ⭐ Add/remove movies from favorites
- ❤️ Favorites page to view saved movies
- 🔄 Page navigation using React Router
- 📱 Responsive UI (basic)

---

## 🛠️ Tech Stack

- React.js
- React Router DOM
- JavaScript (ES6+)
- CSS
- Movie API (e.g. TMDB API)

---

## 🌐 API Used

This project uses a movie API to fetch data.

Example:
- Popular Movies
- Search Movies

You need an API key to run this project.
